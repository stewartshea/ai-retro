Methodology

Every figure below comes from a single primary source: the "How Hungry is AI?" inference benchmark (arXiv 2505.09598, v6), which models 30 frontier models as actually deployed in commercial datacenters — inferring hardware configuration from public API throughput and latency, then multiplying runtime by GPU + non-GPU power. We use its 1,000 input / 1,000 output column, which is 2,000 tokens of work, and divide by two to get a per-1K-token rate.

Those published numbers are facility energy, PUE already included — the paper's own formula multiplies by PUE, and it reports 0.42 Wh for a short GPT-4o prompt against 0.37 Wh "without datacenter overhead." So we apply no PUE factor of our own; doing so would inflate every result by ~30%.

The spread is real and we show it rather than hide it. Reasoning models carry by far the widest error bars (±41% for o3) because hidden chain-of-thought length is unpredictable. Grid carbon intensity defaults to 400 gCO₂/kWh (IEA global average) and is the largest remaining source of uncertainty — your provider's actual region and time-of-day load can differ by 5×.

Two honest caveats. First, these rates assume a 50/50 input-output mix; real sessions skew toward input (prefill is cheaper than decode), so a chat-heavy week will read lower than this table suggests. Second, deployment matters more than model size — the paper measures DeepSeek-R1 at 12.3 ± 4.7 Wh/1K on DeepSeek's own servers versus 2.17 ± 0.58 for the same weights served on Azure, a 5× swing from hardware alone. Haiku outscoring Sonnet above is the same effect, not a typo.
